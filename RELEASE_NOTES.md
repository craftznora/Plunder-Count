**English** · Download **`PlunderCount.exe`** below and run it. Nothing to install. Already using it? Press **U** in the counter: your history and settings are kept.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. Plunder Count only reads these replay files: no game modification, no access to the game's memory. Its only network access is the update check on GitHub (can be turned off).

**What's new in 1.3.0**
- **Simple stream overlay**: `stream.html` in the data folder is a small bar with your total and this session's chests, for an OBS browser source
- New console home screen, dial overlay, star chart and loot insights from 1.2

Windows may show *"Windows protected your PC"* (unsigned exe): *More info → Run anyway*.
